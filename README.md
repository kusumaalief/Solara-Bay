Solara Bay is a 3D blocky open-world crime game in the spirit of GTA 6, built with Three.js (vendored locally — the game makes no network requests). You play Leo Marin, back in Solara Bay and in debt: explore a 640×480 blocky city on foot or behind the wheel, steal cars, outrun the police as your wanted level climbs, and run three story missions — Borrowed Wheels, The Courier, and the Bay Heist. It has traffic and pedestrians, combat, a wanted system with police cars and foot officers, a HUD with cash, health, wanted stars and a live minimap, a start screen, and save games (localStorage). All city, characters, vehicles, names, story, art and sound are original.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in a desktop browser
```

Controls: WASD move/drive · mouse drag to look · click to shoot · E enter a car · F interact · Q punch · Space jump · Shift run · P pause · C save · M mute. Staged screenshot scenes are available at `?shot=chase|drive|mission|menu&seed=7`.
